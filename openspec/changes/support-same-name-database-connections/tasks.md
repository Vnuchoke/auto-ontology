# Tasks

Это задачи будущей реализации, не журнал выполненной разработки. Все пункты остаются незавершёнными до отдельного `/opsx-apply`. Группы — work packages одного согласованного релиза, не независимо развёртываемые фазы. Ссылки на решения — в [design.md](design.md); проверяемое поведение — в двух [delta-spec](specs/database-connections/spec.md) [capabilities](specs/source-scoped-querying/spec.md).

Не устанавливать инструменты и не использовать реальные production/Vault данные без отдельного разрешения. Новые имена test/helper файлов ниже — планируемые файлы, не утверждение об их наличии.
